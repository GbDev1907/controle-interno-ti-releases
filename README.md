# Controle Interno de TI — releases

Este repositório público contém somente instaladores e metadados de atualização do aplicativo Windows Controle Interno de TI. O código-fonte e os dados operacionais permanecem em seus repositórios e sistemas próprios.

## Instalação

Baixe o instalador mais recente em [Releases](https://github.com/GbDev1907/controle-interno-ti-releases/releases/latest). O Windows pode exibir um aviso de segurança porque o instalador não possui assinatura de código comercial; confirme a origem antes de executar.

Não publique neste repositório dados corporativos, credenciais ou arquivos além dos artefatos de instalação.
